## How this list is maintained

1. Community shares are collected from public Reddit threads, GitHub curated lists, Facebook posts, and X.
2. Deals are stored in a Notion database with category, discount, price, expiry, and source link.
3. The list is rebuilt automatically after every collection run (every 6 hours); duplicates are merged by deal URL and title. This README is the index; each category has its own index file, and deals are grouped in subcategory files by purpose.
